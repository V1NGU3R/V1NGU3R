## 📂 Projetos em destaque

### 🥫 Despensa Inteligente
Aplicação acadêmica voltada à organização de alimentos e ao gerenciamento de produtos, lotes, quantidades e compras.

- Desenvolvimento mobile com React Native e TypeScript.
- Integração com API REST.
- Autenticação de usuários e navegação entre telas.
- Projeto em desenvolvimento.
  
  https://github.com/V1NGU3R/despensa_inteligente_frontend

### 🎮 GameVault
Projeto mobile para explorar e organizar uma biblioteca de jogos.

- Desenvolvimento com React Native.
- Integração com API externa.
- Funcionalidades relacionadas a jogos e favoritos.
  
  https://github.com/V1NGU3R/projeto_gamevault
  

### 🎬 Catalogo De Filme
Projeto web para biblioteca de filmes

- Desenvolvimento com React
- Integração com API
- Funcionalidades de busca e filtragem
  
  https://github.com/V1NGU3R/catalogo_filmes
